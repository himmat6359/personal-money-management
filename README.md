# MyMoney — Personal Money Management

A free, responsive personal finance tracker.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Add transactions and set your monthly budget.

## Deploy free on Vercel
1. Create a free account at https://vercel.com/
2. Create a GitHub repository and upload `index.html`.
3. In Vercel, choose **Add New → Project** and import that repository.
4. Deploy with the default settings. Vercel will provide a free `*.vercel.app` URL and HTTPS.

## Important data note
This starter version stores transactions in the browser's localStorage. Data stays in that browser on that device; it is not synced between devices and can be lost if browser site data is cleared. It does not yet have user accounts or a cloud database. Do not enter bank passwords, card PINs, or other highly sensitive credentials.
